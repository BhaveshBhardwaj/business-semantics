📐 Key Engineering Innovations

1. Strict Zero Cross-Country Separation

EDA confirmed 100% of ground-truth matches exist within the same country partition (0.00% cross-country pairs). Partitioning splits the 10M test space cleanly into 3 independent linear streams.

2. Leet-Speak & Punctuation Reversal

Pre-compiled regexes replace zero-to-o, one-to-l, three-to-e, and five-to-s inside words, boosting token overlap recall on ground truth to 99.97%.

3. F_0.5 Threshold Calibration

Because F_0.5 weights precision 2x over recall, the threshold was strictly optimized on held-out validation data to T = 0.65, eliminating costly false merges on singletons.
